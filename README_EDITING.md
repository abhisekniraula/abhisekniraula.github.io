# Editing the Abhisek Niraula website

The site is plain HTML, CSS and JavaScript. It needs no build step and no framework, and GitHub Pages serves it as-is.

## Update content (most edits)

Nearly all text lives in **`assets/js/site-data.js`**. Open it in VS Code or Notepad++ and edit the text inside the quotation marks.

| What | Where in `site-data.js` |
|---|---|
| Name, title, summary, emails, CV file, hero image | `profile` |
| Rotating words in the home headline | `profile.rotatingFocus` |
| Headline numbers on the home page | `stats` |
| The three disease cards on the home page | `pillars` |
| Research projects (Research page) | `projects` |
| Published, submitted and in-preparation papers | `publications` |
| Talks and posters (+ photos) | `presentations` |
| CV sections | `education`, `experience`, `funding`, `skills`, `mentoring`, `affiliations` |
| Awards and service | `honors`, `professionalActivities` |
| Media cards | `media` (only entries with a `url` are shown) |

A few features run automatically:

- Your name ("Niraula, A.") is highlighted in author lists.
- Species names (*Histomonas*, *Eimeria*, *Clostridium*, *Salmonella*…) are italicised.
- Cite / BibTeX, filters, counts and search are generated from the data.
- A presentation with an `image` also appears in the Media page's photo gallery.
- A project or presentation without an image gets a generated "micrograph" illustration.

## Images

- Presentation photos go in `assets/presentations/`. Keep them around 1600 px on the long side; that is plenty for the web.
- Project images go in `assets/project-images/`. Set the project's `image` path to use one.
- The hero illustration is `assets/img/histomonas-hero.webp`. The social-share card is `assets/img/og-card.jpg`.

## Preview on your computer

From the repo folder, run `python -m http.server 8000`, then open http://localhost:8000.

## Editing inside the browser

Add `?edit=true` to any page URL (for example `index.html?edit=true`). Edit the JSON, click **Preview**, then click **Download site-data.js**. Replace the old file with the downloaded one. Click **Exit preview** to go back to the published data.

## Changing navigation, page titles or page layout

The page shells (head, menu, footer) are generated by `tools/build_pages.py`. Edit that file, then run:

```
python tools/build_pages.py
```

Styling lives in `assets/css/styles.css`. The colours are set at the top of that file (`:root` for dark mode, `html[data-theme="light"]` for light "brightfield" mode).

## Interactive extras

- **Histomonas cursor:** a tiny *Histomonas* replaces the mouse pointer while the page is scrolling.
- **Live microscope hero:** cells drift across the home page, and the pointer pushes them away.
- **Command palette:** press **Ctrl K** (or ⌘K), or **/**, to search pages, papers, talks and projects.
- **Themes:** a dark / brightfield theme toggle. The site respects `prefers-reduced-motion`.
